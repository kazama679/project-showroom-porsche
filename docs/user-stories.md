# Porsche Showroom - User Stories

## Epic 1: Authentication & User Management
* **US1.1:** As a user, I want to register for a Porsche ID so that I can securely manage my configurations and test drives.
* **US1.2:** As a user, I want to verify my email using an OTP so that I can activate my account securely.
* **US1.3:** As a user, I want to log in using my email and password so that I can access my personalized dashboard and saved configurations.
* **US1.4:** As a user, I want my session to automatically refresh securely using a refresh token so that I don't have to keep logging in continually.
* **US1.5:** As an admin, I want to log in so that I can access the admin portal to manage vehicles, options, and customer requests.

## Epic 2: Public Showroom & Vehicle Browsing
* **US2.1:** As a visitor, I want to view a list of all Porsche models so that I can see the current lineup.
* **US2.2:** As a visitor, I want to filter vehicles by body style and price so that I can find a model that fits my criteria.
* **US2.3:** As a visitor, I want to view detailed specifications (engine, 0-60, top speed) for each model so that I can compare performance.
* **US2.4:** As a visitor, I want to search through available dealer inventory so that I can find cars that are ready to purchase immediately.

## Epic 3: Vehicle Configurator
* **US3.1:** As a user, I want to configure a vehicle by selecting exterior colors, wheels, and interior materials so that I can personalize my Porsche.
* **US3.2:** As a user, I want to see a live 3D / high-quality gallery preview of my selections so that I can visualize the final car.
* **US3.3:** As a user, I want to see the total price updated in real-time as I select options so that I can stay within my budget.
* **US3.4:** As a user, I want to expand a summary view of all my selected options so that I can review my build before finalizing.
* **US3.5:** As an authenticated user, I want to save my configuration to my account so that I can retrieve it later.
* **US3.6:** As a visitor, I want to generate a unique "Porsche Code" for my build so that I can share it or retrieve it later without needing an account.

## Epic 4: Customer Actions (Test Drive & Inquiry)
* **US4.1:** As a user, I want to request a test drive for a specific model at my preferred date and time so that I can experience the car in person.
* **US4.2:** As a user, I want to submit a "Contact Dealer" request with my configuration so that a dealer can follow up with me regarding pricing and availability.
* **US4.3:** As a user, I want to receive an email confirmation after submitting a inquiry or test drive request so that I know it was received successfully.
* **US4.4:** As a user, I want to search and select a nearby Porsche Center based on my location so that my request goes to the correct dealership.

## Epic 5: Admin Management Portal
* **US5.1:** As an admin, I want to manage the catalog of car series and models so that the showroom website is always up to date.
* **US5.2:** As an admin, I want to configure the available option groups, items, and pricing for each car model so that users have accurate choices in the configurator.
* **US5.3:** As an admin, I want to view and manage customer test drive requests so that I can approve or reject them based on availability.
* **US5.4:** As an admin, I want to view the status of all user inquiries (Pending, Responded) so that dealers can track leads efficiently.
* **US5.5:** As an admin, I want to manage the home page banners and content so that marketing promotions are displayed correctly.
